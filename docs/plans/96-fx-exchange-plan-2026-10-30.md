# 96 — 달러 환전 계획 (2026-10-30)

## 배경

해외 종목을 적립식으로 사는 사용자는 "지금 환전해도 되나, 얼마나 해 둬야 하나"를 앱 밖에서 판단하고 있었다. 이미 있는 실시간 USD/KRW, 목표 환율 알림(5분 잡), 시장 신호의 환율 20일선 이격도, 계좌별 `deposit_usd`를 묶어 환전 판단으로 이어 주는 화면이 없었다.

사용자가 확정한 범위:

- **전망은 통계적 위치와 범위로만** 보여준다. 1년 백분위, 20·60일선 이격도, 1개월 ±1σ다. 예측이 아니라는 고지를 화면에 단다. 외부 기관 전망치는 무료로 안정적인 소스가 없어 제외했다.
- **필요한 달러는 자동 산출**한다.
- **실행 연결은 기존 환율 알림(BELOW) 등록까지**다. 3사 연동 모두 환전 주문 API를 쓰지 않으므로 실제 환전은 증권사 앱에서 한다.
- 저장과 진행 추적은 하지 않는다. 마이그레이션도 없다.

## 구현

| 영역 | 내용 |
|---|---|
| `services/fx_plan_service.py` | `compute_fx_position`(순수): 1년 종가에서 백분위·이평·로그수익률 σ×√21×현재가를 구하고, 백분위 33/67로 CHEAP/NEUTRAL/EXPENSIVE를 나눈다. `compute_fx_plan`(순수): "지금" 비중은 zone별 50/34/20%, 나머지는 `현재−0.5σ`·`현재−1σ`(10원 내림) 2구간에 반씩 둔다. `get_fx_plan`: 포트폴리오는 지정 → 정기 적립 자동매수 → 해외 비중이 있는 첫 포트폴리오 순으로 고른다. 필요 달러 = 월 적립액 × 해외 비중 / 환율 × 개월 − 보유 달러(연결 계좌, 없으면 활성 브로커 계좌 전체)다 |
| 해외 비중 판정 | `dca_cash_shortfall_service._buy_market`을 공개 `buy_market`으로 바꿔 재사용한다. ISA·연금 포트폴리오에서 지수 그룹을 국내 대체 종목으로 사는 비중은 해외에서 뺀다 |
| 시세 | Yahoo `USDKRW=X` 1년 일봉을 `fetch_yf_close_series` + `run_yf_bounded`(공유 세마포어)로 가져온다. 6h 전역 캐시(`usd_krw_history_key`)이며, 관측치 60개 미만은 캐시하지 않는다. 현재값은 앱 전역 실시간 캐시(`get_usd_krw_rate`)를 쓴다. 시세 실패 시 위치 없이 "적립일에 환전" 1구간으로 낸다 |
| API | `GET /invest/fx-plan?portfolio_id=&months=`(1~12, 30/min). 남의 포트폴리오면 404. status: OK/SUFFICIENT/NO_DEPOSIT_GOAL/NO_OVERSEAS/NO_PORTFOLIO |
| 프론트 | `invest/FxPlanCard`: 적립 계획 탭의 접힘 카드다. 1년 범위 바·zone 배지·이격도·±1σ·고지, 기간(1/3/6개월)·포트폴리오 선택, 산식 요약, 구간 표를 보여준다. "목표 환율 알림 등록"은 같은 목표의 활성 BELOW 알림을 건너뛰고 기존 `createExchangeRateAlert`로 만든다. `invalidateDcaData`가 `fxPlanBase`도 무효화한다 |
