# 70. 전술 배분 최적 전술 검토 → 프리셋 비중표 + 신호 규칙 조정 (2026-10-25)

## Context

**방법**
- 실제 시세(QQQ·SPY·QLD·SSO)·VIX·DFII10·DTB3를 썼다.
- 2006-10 ~ 2026-10(20년)을 돌리고, 과적합을 보려고 앞 10년과 뒤 10년도 따로 봤다.

## 해석
1. **샤프는 0.74~0.85로 거의 같다.** 국면 신호의 질은 정해져 있고, 비중표는 수익↔낙폭 사이 위치만 정한다. 그래서 "최적"은 위험 선호의 문제다. 전술 규칙의 공통 가치는 MDD 절감이다(보유 50%대 → 25% 안팎).
2. **기본 비중표는 같은 위험에서 수익이 낮다.** QQQ를 높인 표가 두 구간 모두 CAGR +0.6~1%p, MDD는 같거나 작다. 다만 2006~2026은 나스닥 강세기라 사후 편향이 있다 → 기본값은 유지하고 프리셋으로 제공한다.
3. **매크로(VIX 근사)는 20년 CAGR을 1~1.7%p 깎았다.** MDD를 줄인 건 최근 10년(2020·2022)뿐이다. 실시간 신호와 다르므로 끄기 옵션만 추가한다.
4. **틸트**: 20년 MDD를 악화시켰고(24.7→27.7) 회전율의 약 1/3을 차지한다 → 기본 끔.
5. **밴드 2%**: 성과는 같고 전환이 94회에서 75회로 준다 → 채택.
6. **이진(주식 100%↔현금 100%)은 오히려 나빴다.** 중립 국면에도 주식 100%라 MDD가 컸다. 단계적 축소가 낫다.

## 구현
- `technical_indicators.TREND_BAND_PCT` 1→2. 기술 스냅샷 캐시 키를 v4로 올렸다.
- `tactical_tilt.DEFAULT_TILT_SHIFT_PCT` 10→0. 기존 전략에 저장된 값은 유지한다.
- 전략별 `use_macro`:
  - 마이그레이션 `ta5_tactical_use_macro`: 컬럼 추가, `tilt_shift_pct` server_default를 0으로
  - `classify_regime(use_macro=False)`: 매크로를 GREEN·LIVE로 취급, 근거 "매크로 신호: 반영 안 함(차트 추세만)"
  - `evaluate_market`가 `observed_no_macro`를 추가로 계산하고, `observed_for(..., use_macro)`·`uses_macro()`로 고른다
  - `transition_hints(use_macro=False)`는 매크로 안내를 뺀다
  - 백테스트 `simulate`/`run_tactical_backtest`에 `use_macro`를 추가하고 해시에 포함했다
- 백테스트 캐시 버전을 `tactical_backtest_key` v4 하나로 정리했다. plans/69의 해시 내부 `_BACKTEST_VERSION`은 제거했다.
- 프론트:
  - `TACTICAL_PRESETS`(안정·균형·성장·레버리지)
  - 편집기 상단 2×2 프리셋 카드(누르면 초안만 채움, 일치하면 선택 표시)
  - "매크로 신호 반영" 토글
  - 탭의 알림 토글은 `use_macro`를 함께 보낸다. 매크로를 끄면 상세에 "매크로 반영 안 함"을 표시한다.
