# 50. 요구사항 기준 전체 검토 2차 — 기능 정리·병합 / 모바일 탭 재구성 / 고도화 (2026-10-08)

## Context

사용자 요구 흐름: 전체 자산 모니터링 → 목표(자산·배당) → 기간(단·중·장)×계좌특성(ISA/연금/IRP/일반/해외)별 포트폴리오 추천
→ 시장 모니터링 → 계좌별 절세 계획 → 비중 이탈·리밸런싱 징후 → 매수/매도 알림 → 수동/자동 리밸런싱.

같은 취지의 검토는 2026-09-25에 이미 한 번 했다(`docs/plans/37`, U1~U16 전부 완료, E1·E2·E5·E6·E7 완료).
이번 검토에서는 그 뒤 추가된 기능을 포함해 탭 인벤토리를 다시 조사했다(Explore 3개). 새로 추가된 기능은 절세 액션 플랜, ETF 중복·TER,
지수별 비중, 비중 분석 카드, 기간별 매수, 투자현황 모바일 개선이다.
**결론: 파이프라인은 끝까지 연결돼 있고 죽은 기능은 거의 없다.** 문제는 기능을 추가할 때마다 같은 수치와 같은 개념이 여러 탭에 쌓이는 것이다.
- 주식 평가액·손익 6곳, 배당 5~6곳, 세금 경고 4곳, 시장신호 6곳, 목표 진행률 5곳, 자동화 상태 4곳에 나온다.
- 자산탭은 스위처가 최대 5단 중첩이다.
- "매달 적립" 개념이 서로 모르는 3갈래로 나뉘어 있다(적립 계획 / 챌린지 / 정기 자동매수).

산출물은 `docs/plans/50-full-review-2026-10-08.md`(이 내용) + README 상태표 갱신이고, 아래 Phase 순서대로 구현한다.

## Part 1 — 요구사항 대비 현황 (09-25 대비 변화만)

| 요구사항 | 상태 | 이번 발견 |
|---|---|---|
| 모니터링 | ✅ | 같은 수치가 과다하게 반복됨(→ Part 2) |
| 목표 | ✅ / 부분 | 기간별 목표 금액 없음(E4 미착수) |
| 기간×계좌 추천 | 부분 | 계좌 간 자산 배치(E3) 미착수. **시장신호가 추천에 미치는 효과는 MVO frontier 감쇠뿐**이다(`goal_portfolio_optimizer.py:15,421`). CONSERVATIVE(기본값)·단기·60대+에서는 효과가 0이다. 추천은 raw 레벨, AUTO 게이트는 confirmed 레벨을 써서 서로 불일치한다 |
| 절세 계획 | ✅ | 계획이 아니라 자산탭 4단계 아래(자산›투자현황›세금›한도현황)에 묻혀 있음 |
| 시장 모니터링 | ✅ | 국내 지표는 환율뿐(E8). 나쁜 날에는 시장신호 메일이 최대 4통 간다(다이제스트·등급전환·복합신호·게이트차단) |
| 신호→알림→실행 | ✅ | AUTO를 처음부터 설정하려면 3탭에 걸쳐 약 12탭이 필요하다. 알림 모달에 계좌 연결 링크가 없다(막다른 길) |
| 실행 기록 | 부분 | **앱이 직접 체결한 주문(플랜 leg)이 `TradeRecord`에 기록되지 않아**, 기간별 매수가 스냅샷 추정으로 폴백한다 |
