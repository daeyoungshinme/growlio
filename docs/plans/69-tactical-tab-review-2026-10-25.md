# 69. 전술 탭 검토·고도화 (2026-10-25)

## Context
사용자 요청: 리밸런싱 › 목표 조정 › 전술 탭을 검토해서 개선·고도화해 달라. plans/68(웅덩이·QLD/SSO·분할 적용)을 커밋한 직후, 같은 브랜치에서 검토했다. 사용자는 아래 4개 영역을 모두 하기로 했다.

검토에서 찾은 문제:
1. **분할 적용을 두 번 누르면 75%가 된다.** `interpolate_weights`는 *현재 목표*에서 보간한다. 그래서 "절반 먼저 적용"을 다시 누르면 남은 차이의 절반만 더 옮긴다.
2. **웅덩이 투입량이 실제보다 크게 표시될 수 있다.** 화면은 `dip_shift×단계/3`을 그대로 썼지만, 실제 이동량은 현금 비중으로 캡된다. 일일 알림 문구도 같은 문제가 있었다.
3. **백테스트 응답의 `series`·`regime_timeline`이 화면에 쓰이지 않았다.**
4. **백테스트가 현금 수익률 0·거래비용 0으로 계산했다.** 비교 대상도 SPY·QQQ 100% 보유뿐이라, 타이밍 효과와 "평소 주식 비중이 낮은 효과"를 구분할 수 없었다.
5. **다음 전환까지 얼마나 남았는지, 국면이 며칠째인지 알 수 없었다.** 전략을 끈 상태에서는 관측 국면이 확정 국면처럼 보였다.
6. **모바일에서 탭이 길었다.** 근거 목록·지표 3행×8칸·틸트/웅덩이 근거가 모두 펼쳐져 있었다. DIA 행은 DIA 비중이 0이어도 항상 보였다. 웅덩이 배지는 투입 기준(QQQ)이 아닌 SPY·DIA에도 붙었다.

## 구현

### P1. 정확성·분할 적용
- 마이그레이션 `ta4_add_tactical_partial`: `partial_regime`, `partial_applied_on`.
- `apply_regime_to_portfolio`:
  - `fraction<1`이면 분할 적용 상태를 기록한다.
  - 전체 적용이면 비운다.
- `advance_regime`: 확정 국면이 바뀌면 분할 적용 상태를 비운다.
- `POST /apply`: 같은 국면에서 두 번째 `fraction<1`은 400을 반환한다("이미 절반을 적용했어요").
- `build_status`:
  - `partial_regime`·`partial_applied_on`은 확정 국면과 같을 때만 낸다.
  - `dip_deployed_pct`를 추가했다(`dip_deployed_for` = 틸트 후 현금 − 제안 현금).
- `dip_reasons(..., deployed=)`: 캡이 걸리면 "현금 비중 한도까지"를 붙인다.
- 일일 job: 알림 문구에 실제 투입량을 쓴다. 옮길 현금이 0이면 알리지 않고 기록만 맞춘다.
- 프론트:
  - 분할 적용 상태면 버튼이 "나머지 적용"으로 바뀐다. 확인창에는 전체 적용 버튼 하나만 둔다.
  - "M/D 절반 적용 · 다음 거래일 이후 나머지 적용을 권장해요"를 표시한다.
  - 실행 화면 이동 버튼을 함께 보여준다.

### P2. 백테스트 고도화
- **현금 이자**: FRED `DTB3`(미국 3개월 국채, 연율 %)를 받아 매일 `y/100/252`를 적용한다. 받지 못하면 0으로 계산하고 `macro_note`에 고지한다.
- **거래비용**: 리밸런싱마다 매매한 주식 금액의 0.1%(`_COST_RATE`)를 뺀다.
  - 응답에 `turnover_pct_per_year`를 추가했다(Σ|Δ비중|/2의 연평균).
  - 최초 진입 매수는 비용만 반영하고 회전율에서는 뺀다.
- **"평균 비중 고정" 벤치마크** (`simulate_static`):
  - 전술 배분이 기간 중 평균적으로 든 목표 비중(시간가중, 응답 `avg_weights`)을 처음부터 그대로 두고 매월 리밸런싱한다.
  - `metrics`의 2번째 항목이고, `series.static`으로도 낸다.
- 캐시 키에 `_BACKTEST_VERSION=2`를 넣어 구버전 결과 캐시를 무효화했다.
- 프론트 `TacticalBacktestSection`:
  - 기존 `BacktestResultChart`를 lazy로 재사용한다(누적·연도별·낙폭). 어댑터는 `tacticalLabels.toChartSeries`다.
  - "최근 국면 전환" 목록을 최신순 5건 + 더 보기로 보여준다.
  - 요약에 연 회전율을 넣고, 평균 비중 고정의 의미를 한 줄로 설명한다.

### P3. 전환 조건·지속일
- 신규 순수 모듈 `tactical_hints.transition_hints`가 `classify_regime`·`classify_trend`(±1% 완충, 50/200 교차)를 거꾸로 풀어 다음 전환 후보까지 남은 조건을 만든다.
  - 공격: SPY·QQQ 중 200일선 −1% 이탈선에 더 가까운 쪽의 거리 + "매크로 위험이면 방어 후보"
  - 중립: 공격 진입에 빠진 조건(추세·골든크로스·매크로 안정) + 방어 후보 조건(SPY 데드크로스 상태면 200일선까지 거리)
  - 방어: 매크로 위험 해제 필요 여부 + SPY 하락 추세 해제선(200일선 +1%)까지 거리
- 프론트:
  - 상단에 최대 2줄과 "다음 거래일 재확인" 꼬리말을 표시한다.
  - 배지 아래에 "N일째"를 표시한다.
  - 전략을 끈 상태의 배지는 "{국면} (오늘 관측)"으로 표시한다.

### P4. 모바일 밀도
- 상단에 "지금 할 일" 한 줄(`tacticalNextAction`)을 둔다. 우선순위:
  1. 미사용
  2. 판정 불가
  3. 전환 확인 중
  4. 절반 적용 → 나머지
  5. 미적용 → 적용
  6. 할 일 없음 · N일째
- 틸트·웅덩이는 한 줄 요약으로 줄였다. 다음 항목은 "판정 근거·차트 지표" 접힘으로 옮겼다(`growlio:rebalancing:tactical-details-open`, 기본 접힘).
  - 매크로 확정 등급과 "진단 탭보다 늦게" 안내
  - 근거
  - 지표 행
  - 틸트·웅덩이 근거
- DIA 지표 행은 비중표 어느 국면에든 DIA가 있을 때만 보인다. 웅덩이 배지는 QQQ 행에만 단다.

## 백테스트 실측 (새 기준: 현금 국채 이자·거래비용 0.1%, 기본 비중표·틸트 10%p, 실제 시세·VIX·DFII10·DTB3)

| 구분 | 10년 CAGR / MDD / 샤프 | 20년 CAGR / MDD / 샤프 |
|---|---|---|
| 전술 배분 (웅덩이 끔) | 13.83 / 19.0 / 1.038 | 10.58 / 27.7 / 0.844 |
| 평균 비중 고정 | 14.99 / 24.7 / 0.962 | 11.12 / 43.8 / 0.754 |
| SPY 보유 | 15.35 / 33.7 / 0.886 | 10.95 / 55.2 / 0.632 |
| QQQ 보유 | 20.32 / 35.1 / 0.932 | 16.03 / 53.4 / 0.783 |
| 전술 배분 (웅덩이 20%p) | 14.00 / 19.7 / 1.027 | 10.79 / 27.7 / 0.843 |

- 평균 비중은 10년 기준 QQQ 42·SPY 37·현금 21이다.
- 연 회전율:
  - 웅덩이 끔: 153%(10년), 168%(20년)
  - 웅덩이 20%p: 229%(10년), 246%(20년)
- 국면 전환: 10년 39회, 20년 94회

**해석**
- 국면 판단은 **수익률을 더하지 않는다.** 같은 평균 비중을 그냥 보유하는 쪽이 CAGR이 연 0.5~1.2%p 높다.
- 대신 **낙폭을 크게 줄인다.** MDD가 10년 24.7→19.0, 20년 43.8→27.7로 줄고, 샤프도 높다.
- 즉 이 규칙의 가치는 위험 조정 성과와 하락장 방어에 있다. 이 차이는 화면의 "평균 비중 고정" 줄로 사용자에게 그대로 보인다.
- 회전율의 약 1/3은 월 1회 틸트(10년 45회)에서 나온다. 거래비용 0.1% 기준으로는 연 0.15%p 안팎이다. 세금(해외주식 양도세)은 미반영이라 실제 부담은 더 클 수 있다.
- 웅덩이 투입은 새 기준에서도 효과가 작다: CAGR +0.2%p, 샤프 −0.01. 기본 끔을 유지한다.
