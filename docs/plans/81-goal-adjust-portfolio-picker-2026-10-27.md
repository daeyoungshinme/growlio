# 81. 목표 조정 선택기 정리 — 전술은 전술 켠 포트폴리오 우선, 추천은 적용 영역에서 선택 (2026-10-27)

> 상태: **완료 (PR #166, 커밋 49447556)**. 계획서 없이 머지돼 코드가 인용하는 `plans/81`이 비어 있던 것을 계획 83 B에서 사후 기록했다.

## Context

목표 조정 탭 상단의 "대상 포트폴리오" 선택기 하나를 추천·전술 모드가 함께 썼다(plans/64 S2). URL에 선택이 없으면 기본값은 첫 기준 포트폴리오였다. 이 때문에 두 가지 문제가 있었다.

- **전술**: 기준 포트폴리오는 대개 전술과 무관하다(국내 배당·ISA 등). 그래서 전술 모드에 들어가자마자 "꺼짐"과 "전술 자산 외 종목 삭제" 경고가 보였다.
- **추천**: 추천 비중은 포트폴리오와 무관하게 계산된다. 기간별 추천은 대상이 태그로 자동 결정된다. 따라서 상단 선택기를 바꿔도 결과가 달라지지 않았다.

## 변경

### 백엔드
- `GET /tactical`: 전술 배분을 켠 포트폴리오 목록 `{portfolio_id, confirmed_regime, notify_enabled}`을 반환한다. 저장된 상태만 읽고 시세 조회는 하지 않는다. `tactical_allocation_service.list_strategies` 사용.

### 프론트
- `useSelectedPortfolio(id, { preferTactical })`: 켜면 기본값 우선순위가 전술 켠 포트폴리오, 기준 포트폴리오, 첫 포트폴리오 순이 된다(`QUERY_KEYS.tacticalStrategies`). 목록을 기다리는 동안 `tacticalPending`이면 스켈레톤을 보여 준다. 기준 포트폴리오 상태를 한 번 조회했다가 바뀌는 깜빡임을 막기 위해서다.
- `GoalAdjustTab`: 상단 선택기는 전술 모드에만 둔다. 옵션에는 "(전술 켜짐)"을 표시한다.
- 추천 모드에서는 전체·연령대 추천의 대상을 `RecommendationCard` 적용 영역의 select에서 고른다(URL `portfolioId` 공유는 유지). `showTargetPicker` prop은 삭제했다.

## 후속
- 전술 모드만 기본값이 달라 전술에서 다른 탭으로 옮기면 기준 포트폴리오가 다시 보이던 회귀는 계획 83 A에서 고쳤다.
