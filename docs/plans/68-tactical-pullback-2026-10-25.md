# 68. 전술 배분 × 웅덩이매매법(디벨롭몽) 비교·개선 (2026-10-25)

## Context
사용자 요청: 리밸런싱 › 목표 조정 › 전술 탭을 유튜버 디벨롭몽이 말하는 매크로·차트 관점(웅덩이매매법)과 비교해 개선할 부분을 고쳐 달라.

웅덩이매매법의 상세 규칙은 멤버십 콘텐츠다. 여기서는 공개 요약을 기준으로 삼았다(유튜브 채널 소개, 커뮤니티 Q&A).
- 대상과 보유: 우상향 지수(QLD·SSO·TQQQ 같은 2배·3배 레버리지 ETF)를 10년 이상 적립식으로 보유한다.
- 원칙: "오즐웅줍"(오를 땐 즐기고, 웅덩이에서 줍는다).
- 분할매수: 가격이 20일선 → 60일선 → 120일선까지 눌리고 RSI가 35 아래로 갈수록 더 크게 산다.
  - 20일선: 현금의 10%
  - 60일선·120일선: 각 50%를 며칠에 나눠
  - 120일선 + RSI<35: 남은 현금 전부
- 매도: 거의 하지 않는다.

| 항목 | 웅덩이매매법 | 기존 전술 배분 |
|---|---|---|
| 방향 | 하락할수록 매수(역추세) | SPY 200일선 이탈 시 현금 60%(추세추종) |
| 차트 | 20/60/120일선 터치 + RSI 35 | 50/200일선 추세 판정만, RSI·MACD는 표시만 |
| 상승추세 속 조정 | 핵심 매수 기회 | 신호 없음 |
| 자산 | 2배 레버리지 | QQQ·SPY·DIA·현금 |
| 실행 | 며칠에 걸쳐 분할 | 목표 비중을 한 번에 교체 |

사용자 선택: 아래 4개를 모두 구현한다. 두 철학은 이렇게 조화시켰다.
- 추세가 살아 있을 때만 눌림목을 매수한다.
- 방어 국면 전환이 항상 우선한다.

## 구현

### 1. 웅덩이 단계 표시
- `technical_indicators.py`:
  - 지표: `sma20/60/120`, `classify_pullback`
  - 단계: NONE / SMA20 / SMA60 / SMA120 / SMA120_RSI / UNKNOWN
  - 백테스트용 시계열: `rsi_series`, `pullback_series`
- 스냅샷 캐시 키를 v3로 올렸다.
- 프론트 지표 카드:
  - 50일선 절대가 자리를 종가의 20·60·120·200일선 대비 이격(%)으로 바꿨다.
  - 웅덩이 단계 배지를 추가했다.

### 2. 웅덩이 현금 투입 (`tactical_dip.py`, opt-in, 기본 끔)
- 투입 단계는 QQQ 기준으로 판정한다.
  - 60일선 = 1, 120일선 = 2, 120일선 + RSI<35 = 3
  - 20일선 눌림은 표시만 한다(너무 잦다).
- 투입량은 `dip_shift_pct × 단계/3`이다.
  - 현금에서 빼서 주식 자산에 기존 비율대로 나눈다.
  - 현금 비중이 상한이다.
- 래칫: 한 웅덩이 안에서 단계는 올라가기만 한다. 모든 이평선 위로 회복(NONE)하면 0으로 돌아간다.
- **공격 국면에서만 투입한다.** 중립·방어 국면이면 0이다.
- 적용 순서: 비중표 → 틸트 → 웅덩이.
- 모델: 컬럼 3개 추가(`dip_shift_pct`, `dip_level`, `notified_dip_level`), 마이그레이션 `ta3_add_tactical_dip`.
- API: `PUT /tactical`에 `dip_shift_pct`(0~30)를 추가했다.
- 일일 job: 투입 단계가 깊어지면 `TACTICAL_DIP` 이메일·푸시를 보낸다.
  - 같은 실행에서 국면 알림을 보냈으면 생략한다.
  - 단계가 낮아질 때는 알리지 않는다.

**백테스트(오프라인 스윕, 실제 시세·VIX·DFII10, 기본 비중표·틸트 10%p)**

| 변형 | 10년 CAGR / 샤프 / MDD | 20년 CAGR / 샤프 / MDD |
|---|---|---|
| 웅덩이 끔 | 13.56 / 1.019 / 19.3 | 10.48 / 0.837 / 28.3 |
| 공격+중립, 20%p | 13.66 / 0.987 / 20.8 | 10.76 / 0.828 / 27.6 |
| 120일선 이상만, 20%p | 13.73 / 0.999 / 20.7 | 10.74 / 0.832 / 27.4 |
| RSI 과매도만, 20%p | 13.75 / 1.008 / 19.5 | 10.75 / 0.839 / 27.8 |
| **공격 국면만, 20%p (채택)** | 13.86 / 1.017 / 19.9 | 10.79 / 0.843 / 28.2 |
| 중립 국면만, 20%p | 13.44 / 0.993 / 20.2 | 10.47 / 0.823 / 27.6 |

- 중립 국면의 눌림은 더 깊어지는 경우가 많아 성과가 나빴다. 공격 국면 한정만 샤프를 유지했다.
- 효과는 연 +0.3%p 안팎으로 작다. 그래서 기본은 끔이고, 편집기 문구에도 효과가 작다고 적었다.
- 종료 조건 비교(NONE vs NONE|SMA20)는 차이가 0.1%p 미만이었다. 진입이 적은 NONE을 택했다.

### 3. QLD·SSO(2배 레버리지) 선택 자산
- `TACTICAL_ASSETS`에 QLD·SSO를 추가했다. DIA처럼 기본 0%이고, 0%면 표에서 생략한다.
- 국면 판정과 틸트에는 쓰지 않는다.
- 저장 market은 "NYSE"다(Yahoo PCX 관례). KIS AMS 종목마스터에 두 종목이 모두 있어 주문 시 AMEX로 자동 보정된다(실측 확인).
- 백테스트 수익률:
  - 실제 시세가 있는 날은 실제 수익률을 쓴다.
  - 상장 전·결측일은 `2×기초 − (보수+차입 2%)/252`로 합성한다.
- 편집기는 레버리지 비중이 있으면 복리 감쇠를 경고한다. 방어 국면에 두면 경고를 하나 더 띄운다.
- 참고 비중표(공격 QQQ30·SPY30·QLD20·SSO10·현금10)의 백테스트:
  - 10년: CAGR 15.9 / 샤프 0.97 / MDD 22.3
  - 20년: 12.1 / 0.80 / 30.6
  - 기본 비중표보다 수익은 높고 샤프는 낮다.

### 4. 분할 적용
- `POST /tactical/{id}/apply`가 `{fraction}` 본문을 받는다(0 초과 1 이하, 기본 1).
- `fraction<1`의 동작:
  - 현재 목표에서 제안 쪽으로 그만큼만 보간한다(0.1 단위, 반올림 오차는 현금이 흡수).
  - 전술 자산만 있는 포트폴리오에서만 허용한다(그 외 400).
  - `applied_regime`을 기록하지 않아 적용 버튼이 남는다.
- 확인창을 `Modal`로 바꾸고 "절반 먼저 적용" / "한 번에 적용" 버튼 2개를 뒀다.
