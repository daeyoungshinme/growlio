## Part 2 — 이번 세션 구현 완료

### P0-1. 토스 계좌가 주식 집계 7곳에서 누락 (실버그)
토스 연동(`b8a3d37`) 때 `STOCK_TOSS` enum만 추가되고 서비스별 로컬 주식 타입 집합에는 안 들어갔다. 결과:
토스 계좌는 스냅샷 총액만 합산되고 **주식평가액·매입원가·손익·종목 상세·종목 비중에서 빠짐**, 예수금 분리 안 됨,
대시보드 비주식 기준선에 주식이 섞여 수익률 왜곡, 세금 추정·자산추이 주식 분해·추천 드리프트 알림·백테스트
실보유 비교에서도 제외.
- `app/constants.py`에 `POSITION_STOCK_ASSET_TYPES` 단일 정의, `portfolio_service`(STOCK_TYPES/_EQUITY_TYPES),
  `composition_calculator`, `tax_service`, `portfolio_history_service`(집합+raw SQL), `recommendation_drift_alert_service`,
  `backtest_service`, `asset_aggregator`(raw SQL)가 참조하도록 통일. 라벨 누락(키움/토스) 보강.
- 재발 방지: `tests/test_constants.py` — `AssetType`의 모든 `STOCK_*`가 집합에 있어야 통과(다음 브로커 추가 시
  CI가 잡음). `test_build_portfolio_overview`에 토스 파라미터 추가.

### P0-2. 금융소득 종합과세(2천만) 판정 오류
- `tax_service.get_tax_summary`가 **해외주식 미실현 양도차익을 금융소득에 합산** → 해외 이익이 큰 사용자에게 종합과세
  경고가 잘못 뜨고 잔여 한도가 과소 표시. 해외 양도차익은 양도소득 분류과세라 합산 대상 아님 → 배당만으로 판정.
- `_calc_dividend_income`이 **ISA·연금저축·IRP 계좌 배당까지 15.4% 과세·금융소득에 포함** → 세제혜택 계좌 제외
  (계좌 미지정 배당은 과세로 간주). 건강보험 피부양자 추정도 같은 값을 쓰므로 함께 교정.
- 프론트 문구 3곳("금융소득(배당+해외차익)", 플래너 안내) 정정, 배당소득세 보조문구 "과세계좌 배당".

### UX 저위험 수정
- `AutoInvestStatusBanner`(계획탭): "설정 관리/설정하기"가 목록만 열고 알림 모달은 안 열던 죽은 딥링크 →
  대상이 하나로 정해지면 `portfolioId&openAlert=1`.
- `GoalSettingWizard` 6단계 "이 추천으로 포트폴리오 만들기": 생성 후 계획탭에 머물러 계좌 미연결 고아
  포트폴리오가 남던 흐름 → 생성된 포트폴리오로 이동 + "계좌를 연결하면 진단 시작" 안내.
- 설정탭 "계좌 연동": 전역 KIS 키(`has_kis`)만 봐서 키움·토스 사용자는 "미연결"로 표시 → API 연동 계좌 수 표시,
  라벨 "KIS/키움/토스".
- 계획탭 안내문이 실제 없는 버튼명("처음부터 다시 설정/값만 빠르게 수정")을 가리키던 것 정정, 통계 라벨의

- 자산탭 중복 크롬 제거: 탭 바로 아래 "자산 › 투자현황/계좌관리" 브레드크럼 2개 + 계좌관리 소개문.
- 빈 상태 조사 오류 "등록된 은행계좌이 없습니다" → "가".
- stale 주석 2곳(`DashboardPage` 스냅샷 카드, `TaxLimitsBanner`) 현행화.
