# 71. 적립식 코어 + 전술 보조 — 자동매수 "전술 방어 국면 보류" 게이트 (2026-10-25)

## Context
사용자 요청: "기본은 적립식 투자에 전술은 보조로 진행하면 어떤지 검토해줘". plans/70(전술 최적 스윕)의 후속이다.

**방법**
- 실제 시세(QQQ·SPY), VIX, DTB3를 썼다. 기간은 2006-10 ~ 2026-10이고, 20년 전체와 앞 10년·뒤 10년을 따로 봤다.
- 매달 첫 거래일에 1씩 적립한다. 거래비용 0.1%, 현금 이자를 반영했다.
- 지표:
  - IRR
  - 체감 낙폭: 적립금 포함 평가액의 고점 대비 하락
  - 누적 매도액(원금 대비)
- **양도세는 미반영**이다. 매도가 많은 구조일수록 실제 결과는 더 나쁘다.

## 결과 1 — 전술로 전체 비중을 교체하면 손해 (QQQ·SPY 50:50 기준, 20년)

| 구조 | 배수 | IRR | 체감 낙폭 | 누적 매도(원금 대비) |
|---|---|---|---|---|
| 적립만(매수만) | 6.31× | 16.03% | 36.0% | 0% |
| 적립 + VIX≥30 매수 보류 | 6.25× | 15.95% | 33.5% | 0% |
| 전체 전술(균형형) | 3.95× | 12.21% | 20.6% | 1990% |
| 전체 전술(균형·추세만) | 4.68× | 13.61% | 24.7% | 1534% |
| 코어80 + 전술20 | 5.84× | 15.40% | 28.7% | 398% |
| 코어70 + 전술30 | 5.60× | 15.07% | 27.0% | 597% |

적립식의 강점은 하락장에도 계속 사는 데 있다. 전술 비중 교체는 하락장에 팔아 그 강점을 없앴다. 앞 10년·뒤 10년도 같은 방향이었다(전체 전술이 IRR −3.4~−4.3%p).

## 결과 2 — 같은 자산 비율에서 매수 시점만 조절 (IRR / 체감 낙폭)

| QQQ 80% | 20년 | 앞 10년 | 뒤 10년 |
|---|---|---|---|
| 매달 매수 | 17.40% / 37.4 | 14.11% / 37.4 | 18.96% / 27.8 |
| **방어 국면엔 보류(현금) → 벗어나면 매수** | **17.42% / 32.0** | **14.18% / 18.1** | 18.87% / 27.4 |
| 공격 국면에서만 매수 | 17.00% / 31.9 | 13.07% / 18.1 | 18.45% / 27.4 |
| 적립금 20% 예비 + QQQ 120일선 웅덩이에서 매수 | 17.57% / 37.5 | 14.16% / 37.5 | 18.92% / 27.7 |

- QQQ 50%·100%도 같은 결론이다. 매수 보류는 IRR ±0.2%p 안에서 비슷했고, 금융위기 구간 체감 낙폭은 절반으로 줄었다. 매도가 없어 세금도 없다.
- "공격 국면에서만 매수"는 너무 오래 기다려 −0.4~1%p 손해였다.
- 예비금 방식은 수익이 약간 늘었지만 낙폭은 줄지 않았다.
- 보류한 현금을 국면이 풀리자마자 사든 다음 정기 매수일에 사든 차이는 ±0.1%p였다. 그래서 기존 월 스케줄로 충분하다.
- 방어 국면 비중: 20년 20%, 앞 10년 26%, 뒤 10년 15%.

## 구현
- **게이트 판정** `order_builder.is_market_signal_blocking_auto_mode(..., tactical_regime)`:
  - 새 모드 `TACTICAL`은 같은 포트폴리오 전술 배분의 확정 국면이 RISK_OFF일 때만 차단한다.
  - 복합 신호 등급·STALE은 보지 않는다.
  - 국면을 모르면(전략 없음) 통과한다.
- `order_builder.tactical_regime_for_gate(alert, db)`: TACTICAL일 때만 `TacticalStrategy.last_regime`을 조회한다.
- 이 값을 쓰는 호출부 5곳:
  - AUTO 계획 생성 job
  - 드리프트 알림 체크 2곳
  - 매수 직전 재확인(`plan_execution`)
  - 원클릭 실행(`quick_execute_service`)
- 보류 알림:
  - `MarketSignalGateBlocked.tactical_regime`을 추가했다.
  - TACTICAL이면 이메일(`_tactical_gate_blocked_template`)·푸시·이력 문구가 "적립 매수 보류 — 전술 방어 국면"으로 바뀐다.
  - 원클릭 실행 보류 메시지도 분기한다.
- **실버그 수정**: 게이트 보류 이메일의 모드 라벨이 실제 판정과 반대였다. 지금은 CAUTIOUS=RED만, STRICT=YELLOW·RED로 맞췄다.
- 설정 검증:
  - TACTICAL인데 그 포트폴리오에 전술 배분이 없으면 422를 반환한다(`_validate_tactical_gate`, 통합·계좌별 upsert 모두).
  - 전술 배분을 끄면 연동 알림을 DISABLED로 되돌린다.
- 프론트:
  - 자동매수 설정 "시장 상황 조건"에 "전술 연동" 옵션을 추가했다.
  - `useDcaTacticalLink`(활성 AUTO + BUY_ONLY = 적립 자동매수, 그중 TACTICAL = 연동)를 추가했다.
  - 전술 탭 동작:
    - 적립 자동매수인데 연동하지 않았으면 → 비중 적용 대신 전술 연동을 권하는 안내 + 자동매수 설정 링크
    - 연동 중이면 → "지금 할 일"에 "방어 국면 — 이번 적립 매수는 보류돼요" / "적립 매수 정상 진행 · {국면} N일째". 적용 버튼은 보조 스타일로 낮췄다.
    - 끄면 → 연동 해제 토스트를 띄우고 알림 목록을 갱신한다.
- 마이그레이션 없음(`market_condition_mode`는 String(10)).

## 주의
- 나스닥 강세기(2006~2026) 한 번의 역사다. 매수 보류의 효과는 금융위기처럼 긴 하락장에서 컸고, 짧은 급락(2020)에서는 거의 없었다.
- 보류 중인 현금은 예수금으로 남는다. 다음 정기 매수일의 BUY_ONLY가 목표 비중에 맞춰 함께 매수한다. 이때 하루 합산 상한(`DailyValueCapBlocked`)에 걸리면 나눠서 매수될 수 있다.
